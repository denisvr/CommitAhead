CommitAhead · approved direction

Reading Room

Warm paper, ink navy, one humanist sans. The interface reads as a study desk rather than a console: the page leads with a single decision and its written justification, and everything else recedes into a quiet ranked list. This revision fixes every contrast failure in the original study, bundles all fonts and icons locally, adds a density scale for analytical tables, and uses the approved Bookmark mark.

What changed since the direction study

Contrast, corrected. The study's faint text (#8A8478 light, #767065 dark) failed AA at 3.5:1. Both were retuned to clear 4.5:1 at 12.5px on the tint as well as the sheet — the tint is the tighter constraint — and a --border-strong was added at 3:1 for control edges, which the hairline rules cannot carry.

No CDN. Public Sans (variable) and IBM Plex Mono ship as files in assets/fonts/ with their OFL licences; approved Lucide glyphs ship in assets/icons/ as individual SVGs. Nothing in this project reaches the network at runtime.

Analytical density. Comfortable is the default and governs the queue, item detail and CV editor. data-density="dense" is opt-in per region for analytical tables only — never for a whole page.

Dense keeps the same type family, colours and rules — it changes only vertical padding, row title size and the presence of a zebra tint. Row height drops from 52px to 30px. Dense is never used where a row is a tap target on mobile; there the comfortable scale applies regardless.

Icons — 25 Lucide glyphs, bundled locally

Lucide, stroke-width 1.75 on the 24 grid — roughly 1.17px optical at the 16px display size, matching Public Sans Regular. Files were copied from the Lucide repository (ISC licence included) and the stroke rewritten; nothing is loaded from a CDN. Icons appear in navigation and in confirm/destructive affordances only — never beside a heading, never as a bullet, never coloured except by inheriting currentColor from an active nav item.

Controls, states, severity

Buttons are the only filled surfaces in the interface. Hover darkens navy to #16283A (lightens to #B0CBE6 in dark) — never an opacity change, never a lift or shadow. Press steps one value further, with no transform. Disabled is 45% opacity plus cursor: not-allowed. Destructive actions are outlined in --critical and always require a second confirmation.

Severity is the only place colour carries meaning, plus the accent used once for “AI draft awaiting confirmation”. Every severity chip pairs a colour with a word, so the meaning survives greyscale and colour-blindness. Focus is 2px solid var(--accent) at 2px offset on every interactive element, in both themes, never removed and never replaced by a shadow ring.

Standing rules

No decorative data. Numeric examples respect the domain ranges and EffectiveScore formula; production renders the authoritative API values. No commit hashes, no fake IDs, no invented telemetry — the earlier study's a3f91c2-style metadata is gone, because the product has no such identifier and it was decoration.

No decoration. No gradients, no imagery, no texture, no glass, no card shadows, no coloured left borders on cards, no charts that do not answer a question the user asked. The only permitted graphic is the score breakdown, because it is the product's explanation of itself.

Keyboard first. Full operation without a mouse, including the 1–5 rating control (arrow keys) and Accept/Reject proposal pairs. Visible focus everywhere. Motion is 80–180ms, functional only, and zeroed under prefers-reduced-motion.
