The second confirmation every destructive action requires. The only component in the system that casts a shadow.

```jsx
<Dialog open={open} destructive title="Delete this study item?" confirmLabel="Delete item"
        onConfirm={...} onCancel={...}>
  It has no reviews and no evidence links, so nothing else changes.
</Dialog>
```

State the consequence in the body, not a generic "this cannot be undone".
