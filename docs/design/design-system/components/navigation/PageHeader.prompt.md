Standard page opening: kicker, title, and a one-line statement of what is being shown and why it is in this order.

```jsx
<PageHeader kicker="Tuesday · 18 active items" title="Study Queue"
  summary="Ranked by importance, evidence of demand, and how long ago you last proved you knew it." />
```

The summary is not optional on list screens — explaining the ordering is the product's core promise.
