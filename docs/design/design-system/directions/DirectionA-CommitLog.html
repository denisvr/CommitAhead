Visual direction A

Commit Log

The direction proposed in docs/design/visual-identity.md, tightened. It borrows structurally — not decoratively — from the product's own vocabulary: a ranked list whose row number is the priority order, short monospace ids and “reviewed 3d ago” metadata, and a literary serif for titles that reads like a considered commit message rather than SaaS chrome. Colour is rationed: one deep teal for the brand, three semantics for severity, nothing for categories.

Rationale

Why a serif. Every other surface of this product is code-adjacent. A warm text serif on page titles is the one editorial note that says “thinking tool”, not “dev tool” — and it costs nothing in density because it appears only at title scale.

Why deep teal. Not the GitHub green a commit metaphor would reach for (that hue is reserved for good/matched), not a generic SaaS blue. Dark enough to pass AA on white at 14px, and it holds up as a fill behind white text.

Why hairlines. Study Queue is a list you scan 40 rows of. Dividers and 4–7px radii keep the eye moving down the column; cards with shadows would chunk it into 40 separate objects.

Wordmark

CommitAhead

Type-only, set in the display serif, split at the compound: Commit in ink, Ahead in accent. The optional rule beneath is a commit node on a branch line — used once per surface at most (login, empty states), never as page furniture. No pictorial mark is proposed; the repo contains none, and one would have to be commissioned rather than invented.

Icons: Lucide, 1.5px stroke, 16/20px. The repo ships no icon set; Lucide is the closest match to this direction's hairline weight and squared-off joins. Icons are navigational and never decorative — no icon appears next to a heading or inside a paragraph.

Component character. Radii 4–7px. One hairline, never two. Surfaces sit on a slightly darker ground; the only shadow in the system is a 1px lift. Controls are 30/38px tall. Focus is a 2px accent outline at 2px offset, on everything.
